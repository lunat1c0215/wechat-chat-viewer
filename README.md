# 微信聊天记录查看器

在 Windows 上查看本机微信 4.x 的聊天记录：自动侦测账号、自动提取密钥、临时解密，
以气泡界面浏览会话与消息。**解密数据只存在于临时目录，退出即清除。**

> 当前版本：**1.0.0** · 适配微信 4.0.x / 4.1.x（含 4.1.15.13 新密钥形式）

---

## 功能

| 模块 | 说明 |
|---|---|
| 自动侦测 | 自动发现微信进程、版本与数据目录（支持数据目录不在 C 盘） |
| 密钥提取 | 从运行中的微信进程内存提取数据库密钥，无需手动填写 |
| 临时解密 | 解密到系统临时目录，退出程序自动删除，不修改微信任何文件 |
| 会话列表 | 单聊 / 群聊 / 公众号分类，按时间或消息数排序，支持正序 / 倒序 |
| 气泡聊天 | 自己右侧绿色气泡、对方左侧白色气泡，群聊显示发送人，日期分隔 |
| 图片 | 本地 `.dat` 自动解密显示，动图 `wxgf` 取首帧，点击查看大图 |
| 表情 | 优先读取本地缓存，缺失时从 CDN 补全；可选用「快速启动」跳过 |
| 消息类型 | 文本 / 图片 / 语音 / 视频 / 表情 / 文件 / 链接 / 小程序 / 视频号 / 转账 / 红包 / 合并转发 / 拍了拍 / 系统消息 |
| 检索与导出 | 会话内搜索、日期过滤、导出 CSV / TXT |
| 统计 | 消息总数、收发比、类型分布、时间范围 |

## 快速开始

### 方式一：使用发布包（推荐）

1. 在 [Releases](https://github.com/lunat1c0215/wechat-chat-viewer/releases) 下载
   `wechat-chat-viewer-v1.0.0-win64.zip`
2. 解压到任意目录（**不要**放系统目录）
3. 先运行并登录电脑版微信
4. 双击 `启动查看器.bat`

> 首次运行可能触发杀毒软件误报（程序会读取微信进程内存用于取密钥），
> 选择「仍要运行」即可。

### 方式二：从源码运行

```powershell
pip install -r requirements.txt
python src\微信聊天记录查看器.py
```

## 使用流程

1. 启动程序，主界面直接显示「正在检测微信」，不弹空窗
2. 检测到账号后，**同一张卡片**显示头像、微信号、库数量、体积与「进入」，
   可勾选「加载表情图片」（不再弹第二个确认窗口）
3. 点「进入」后自动串完：读取内存密钥 → 临时解密 → 进入查看器，
   每一步都有真实进度，随时可「取消」
4. 进入查看器即可浏览：会话列表先出来，头像 / 图片 / 表情在后台继续准备，
   不阻塞操作；超长会话只渲染最近 150 条，顶部可点「显示更早」
5. 关闭程序：窗口立即消失，临时解密数据交给独立清理进程删除

> 若提示无权限读取内存，程序会请求以管理员身份重新执行。

## 数据安全

- 只读取本机微信数据与进程内存，**不联网、不上传**
- 解密结果写入系统临时目录，程序退出时删除
- 不修改微信任何文件，不写入注册表
- 每次启动重新解密，不保留上次结果

## 常见问题

**Q：提示「解密失败 / 未提取到密钥」？**
确认微信已运行并登录；确认微信版本为 4.x；尝试以管理员身份运行。

**Q：换电脑或换账号还能用吗？**
可以。密钥与数据目录都在运行时从本机重新获取。

**Q：会修改我的微信数据吗？**
不会。全程只读，解密副本放在临时目录并在退出时删除。

**Q：支持微信 3.x 吗？**
不支持，仅适配微信 4.x 的数据结构。
